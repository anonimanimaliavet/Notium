# Notium Pro — APK
Bu proje Android Studio/Gradle ile APK'ya çevrilebilir.
Gereksinim: JDK 17+, Android SDK (API 35) ve Android Gradle Plugin 8.7.3.
Komut: `gradle :app:assembleDebug`
APK: `app/build/outputs/apk/debug/app-debug.apk`
Not: Bu çalışma ortamında Android SDK/build-tools kurulu olmadığı için APK binary'si burada derlenemedi; kaynak proje APK üretmeye hazırdır.
